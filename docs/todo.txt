
# Prompt example

Write **short, structured articles**. They are **compressed explanations** of what *you now actually understand*. Build the article in the form of a sequential presentation of questions and answers to them, from the general to the specific.

These articles are: **not tutorials**, **not blog spam**, **not copied from docs**

Why this step is critical:
- Interviews test *verbal compression*, not raw coding ability
- Writing forces you to structure mental models
- These texts become: interview prep notes, LinkedIn / GitHub material, personal reference docs

Expected outcome:
I can explain: *why* it is needed, *where* it helps, *where* it should be forbidden
